# Knowledge

设计知识与风格资产的存放处。Skills 通过相对仓库路径按需引用。

## 目录

| 路径 | 用途 |
|---|---|
| `design-styles/` | 可执行风格包（P1：仅规范，不全量迁移） |
| `brand/` | 品牌分析常用规则与模板 |
| `web/` | Web 专属知识 |
| `presentation/` | PPT / Deck 专属知识 |

## 风格包最低字段（迁移标准）

每种风格一个目录或一个 markdown 文件，建议包含：

1. id / name / category  
2. 定位与气质（大胆/中性/安静）  
3. 视觉特征（可观察）  
4. 色彩策略（非死抄 hex 配方）  
5. 字体策略  
6. 布局策略  
7. 图像策略  
8. 装饰元素  
9. 适用 / 不适用场景  
10. 示例或 specimen 路径  
11. 参考来源  
12. **许可证信息**  

无许可证信息的资产不得合并入默认可分发集合。

## P1 范围

- 建立组织方式与筛选标准（见 `design-styles/SELECTION_CRITERIA.md`）。  
- **不**迁移 Huashu 全部 84 风格与样张。  
- **不**复制 BGM/SFX。

# 风格筛选与迁移标准（P1）

第一阶段目标：建立 **10–20** 个候选风格的筛选标准，而不是拷贝全库。

## 纳入候选的条件

1. 可用纯 HTML/CSS（或明确标注降级点）表达主体。  
2. 有可观察的布局差异，不只靠配色命名。  
3. 提供可执行参数（网格、字号关系、留白、材质）。  
4. 标本或示例不侵犯第三方商标（或已获许可）。  
5. 许可证可写入文件头（MIT / OFL / CC0 / 自有等）。

## 排除或暂缓

1. 强依赖未授权字体或库存图。  
2. 还原度依赖生图且无降级方案。  
3. 与已有候选骨架重复。  
4. 仅有名称与一张情绪图、无可执行规则。

## 质量优先于数量

拒绝「凑满 84」。社区贡献按本标准审阅。

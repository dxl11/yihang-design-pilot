# Visual Direction（已选）— 启航学堂 · Direction B「青绿工作室」

- Skill: web-visual-direction
- 日期: 2026-11-03
- 选定：Direction B

## 气质

冷静、专业、干净、可信；像技能工作室而非促销课广告。

## 色彩

| 角色 | 方向 |
|---|---|
| 表面 | 浅灰绿 / 近白冷调 |
| 主色 | 深青绿（非荧光） |
| 正文 | 石墨近黑 |
| 次级文字 | 中灰 |
| 强调 | 主色用于 CTA / 关键链接 |

## 字体

- Display：几何无衬线（实现时选定开源许可字体，如与项目许可兼容的方案）  
- Body：高 x-height 无衬线；中文优先系统或已许可字体栈  
- 正文最小 16px 等效；移动正文 ≥14px 硬底线按项目规范执行

## 布局骨架（首页）

1. 全宽英雄氛围层：品牌名主导 + 一句定位 + 主/次 CTA  
2. 双产品线分区（任务导向，非装饰卡片墙）  
3. 信任条：教研或成果（授权后）  
4. FAQ 摘要 → 申请 CTA  

## 图像语言

真实学习/作品局部；禁止假 logo、裂图、无授权肖像。

## 运动

克制：首屏轻微氛围位移；CTA hover 状态清晰；避免炫光粒子。

## 禁止项

紫粉 AI 模板渐变、霓虹描边、倒计时促销条、无意义浮动徽章、首屏统计条堆砌。

# Page Design — 价格与方案 Pricing (`/pricing`)

- Skill: web-page-design
- 日期: 2026-11-03
- 页面类型: Pricing Page
- 置信度: low–medium（**定价档位未定稿**）
- 上游: Brief · IA · Direction B · Design System · tokens
- **IA 关系**: IA 明确「未纳入首期」价格独立页；Brief 客单价区间口述 199–1299 **未最终定档**。本页为 **策略验证**：比较框架 + 风险消除 + **咨询定价**，**不输出任何 FACT 价格数字**。[FACT]

## 1. Overview

### 目标

| 层 | 内容 | 标记 |
|---|---|---|
| 商业 | 解释如何选择投入方式；促成咨询/试听而非即时未确认成交 | INFER + FACT（价格未定） |
| 用户 | 理解档位差异维度；降低「买贵/买错」焦虑 | HYPOTHESIS |
| 成功 | 用户提交「帮我推荐档位」或试听申请 | 建议 TODO |

### 类型选型

**Pricing**：比较与决策页。与 Home 不同——几乎不讲品牌故事；与 Course Detail 不同——不展开大纲，而展开**权益维度与选择逻辑**。

### 用户任务

1. P0：有哪些方案维度（课量、答疑、陪跑等）— 维度名可 PLACEHOLDER。[TODO]  
2. P0：如何选择；不确定时找人问。[FACT 需求]  
3. P1：退款/重学等政策 — **无文案则 TODO，不编造保障**。[TODO]  
4. P0：采取咨询或试听行动。[FACT]

### 设计策略

1. 首屏：说明「档位调整中，以下为选择框架」诚实状态，避免假折扣钟。  
2. 三列（或两列）**方案骨架卡**：列权益维度对比，价格位显示「咨询报价」而非 ¥。  
3. 「如何选择」决策引导（转行入门 vs 进阶）。  
4. 风险消除：FAQ；政策仅在有法务文案后启用。  
5. 主 CTA：`咨询适合我的方案` → `/apply?intent=pricing`；次：`先试听`。  

### 关键决策

- 口述区间 199–1299 **不得**写成页面标价 FACT；若展示，仅可出现在内部备注或标 `SOURCE: 客户口述未定稿` 且默认不对用户显示。[FACT]  
- 上线前若仍无定价：本页可降级为「方案说明 + 咨询」，或自导航隐藏。[TODO]

## 2. Structure

| # | 区块 | 目标 |
|---|---|---|
| 1 | Header | 导航；弱化促销感 |
| 2 | Pricing hero | 选择框架说明 + 诚实「价格确认中」 |
| 3 | 方案比较表/卡 | 维度对比；价格格 = 咨询 |
| 4 | 如何选择 | 3 步决策启发式 |
| 5 | 含什么 / 不含什么 | 边界清晰 |
| 6 | 保障与政策 | 仅真实文案；否则折叠为 TODO 注释 |
| 7 | FAQ | 支付、发票、退费（答案待法务） |
| 8 | 终局双 CTA | 咨询方案 / 试听 |
| 9 | Footer | |

### 信息层级

- P0：框架说明、对比维度、主 CTA  
- P1：如何选择、边界  
- P2：政策细节、发票  

### 顺序理由

先管理「为什么还看不到标价」的预期，再给比较结构，再用选择引导降低决策负荷，最后行动——避免未定价时首屏大字金额引发不信任或虚假承诺。

### 入口 / 出口

- 入：课程卡「了解投入」、Course Detail 次 CTA、未来广告。  
- 出：`/apply`、`/courses`、`/faq`。  
- 若 IA 最终坚持不上独立定价页：本规格可迁到 Course Detail 的「投入说明」折叠块。[TODO]

## 3. Layout

- 比较区：桌面 3 列等宽（`lg+`）；`md` 可横滑或堆叠；强调中间档用 `border.strong` + 轻微 `brandSubtle` 背景，**不用**荧光角标「最畅销」除非有数据 FACT。  
- 表格式备选：行 = 权益，列 = 方案；移动转卡片。  
- 容器/间距/字体继承系统；价格单元格排版预留，但内容为按钮「获取报价」。  
- **禁止**另造促销红黄全局色；警告用 `status.warning` 仅用于「价格确认中」提示条。  
- **不新增全局 tokens**。

## 4. Interaction

### 主 CTA「咨询适合我的方案」

| 项 | 定义 |
|---|---|
| 触发 | Hero、每卡底部、终局带 |
| 行为 | `/apply?intent=pricing&plan=<skeleton-id>` |
| 成功 | 到达表单；intent 可预填需求类型 |
| 失败 | 无 plan 参数仍可提交意向 |
| 状态 | hover / focus-visible；提交态在 apply 页定义 |

### 次 CTA「申请试听」

→ `/apply?intent=trial`；secondary 样式。

### 方案卡切换（若移动手风琴）

仅改变可见权益，不改变未确认价格。

### 空态 / 异常

- 方案维度尚未配置：显示单一「联系顾问定制」块，隐藏空比较表。[TODO]  
- **永不**显示随机生成的假 ¥ 标价。

## 5. Content

### 文案结构

- H1：`学习方案与投入`（或同等中性表述）  
- 诚实提示：`具体档位与价格仍在确认，提交需求后由顾问回复` [FACT 状态]  
- 方案名 PLACEHOLDER：`入门 / 系统 / 进阶陪跑` — 名称待商务确认  
- 对比行 PLACEHOLDER：课程模块数、直播答疑次数、作业批改 — 次数不填假数字  
- CTA：`咨询适合我的方案` / `先申请试听`  
- FAQ 问句可写；答句无政策时写「答复筹备中」而非编造「无条件退款」  

### 绝对禁止作为 FACT 展示

- 具体标价、划线价、限时折扣百分比  
- 「已有 N 人购买」  
- 伪造支付品牌背书图  

### 素材

简洁比较图标；无人物证言图。

# Visual Directions — 启航学堂

- Skill: web-visual-direction
- 日期: 2026-11-03
- 输入: Brief（青绿、干净、可信、非廉价广告）+ IA（营销官网首页为样例页）

## Direction A — 「日照课桌」

- **一句话气质**：温暖、贴近学习者日常。  
- **色**：暖纸色底 + 墨绿强调（非荧光绿）。  
- **字**：人文衬线标题 + 清晰无衬线正文。  
- **骨架**：首屏左文右课堂实拍；下方双产品线横卡。  
- **图像语言**：真实课堂/作业局部，忌卡通吉祥物轰炸。  
- **禁止**：大红大绿促销条、假优惠倒计时。  
- **风险**：衬线在移动端需控制字号；素材授权不足时易空。

## Direction B — 「青绿工作室」（推荐候选）

- **一句话气质**：冷静专业的技能工作室，干净可信。  
- **色**：浅灰绿表面 + 深青绿主色 + 石墨正文。  
- **字**：几何无衬线显示字 + 高可读正文（中英混排友好）。  
- **骨架**：全宽首屏氛围底（柔和渐变/真实桌面纹理）+ 品牌名主导 + 一句定位 + 双 CTA；下接双产品线分区（非卡片堆砌首页）。  
- **图像语言**：产品界面局部、学习场景特写；少而精。  
- **禁止**：紫粉渐变模板、霓虹 CTA、无意义徽章贴纸。  
- **风险**：过「冷」可能削弱亲和；需用真实场景图平衡。

## Direction C — 「编辑部简报」

- **一句话气质**：信息清楚的教育编辑部。  
- **色**：白底、黑字、有限青绿点缀。  
- **字**：强层级无衬线，接近编辑排版。  
- **骨架**：首屏大标题 + 短栏说明 + 目录式产品入口。  
- **禁止**：假报纸纹理堆砌、过密多栏移动难读。  
- **风险**：易显「文档站」，招生感偏弱。

# Design Brief — 启航学堂官网

- 生成 Skill: web-design-brief
- 日期: 2026-11-03
- 置信度: medium（缺正式用户研究与定价定稿）
- 输入来源: `examples/web/online-education-site/00-project-intake.md`

## 1. 项目概述

建设「启航学堂」品牌营销官网（从 0），承接信任建立与试听/咨询转化。首期不含 LMS 与 App。[FACT]

网站类型：营销官网（课程摘要 + 信任内容 + 转化表单）。[INFER]  
业务模式：B2C 在线职业教育 / 录播课 + 答疑。[FACT]  
成熟度：成长期早期（约 1.5 年，现无独立官网）。[FACT]

## 2. 商业背景

当前获客与介绍依赖公众号与第三方课程平台，品牌可控触点弱。[FACT]  
官网目标是建立自有品牌触点并承接咨询/试听。[FACT]

**禁止表述**：未开展正式访谈，不得写成「经用户研究验证的画像」。[FACT]

## 6. 用户场景

1. 首次听说品牌 → 扫一眼教什么 → 决定是否留下联系方式。[INFER]  
2. 对比产品设计 vs 数据分析方向 → 选入门课摘要 → 申请试听。[INFER]  
3. 已购学员找上课入口 → 跳转第三方（是否做深链待定）。[FACT + TODO]

## 7. 核心问题

- 无官网导致介绍碎片化、信任难规模化建立。[INFER]  
- 用户「怕买错」的证据仅限运营闲聊，证据弱。[HYPOTHESIS]  
- 定价档位未定，价格页策略不能锁死。[FACT]

## 8. 网站目标

1. 2 分钟内说清「教什么 / 适不适合我」。[FACT]  
2. 主转化：试听申请或咨询表单提交。[FACT]  
3. 观感专业可信，避免廉价网课广告气质。[FACT]

## 13. 技术与设计约束

- 静态或轻量 CMS；不做 LMS / App / 社区 / 多语言。[FACT]  
- 移动优先（大量微信内打开）。[FACT]  
- 设计阶段约 1–2 周；整体 4–6 周上线期望。[FACT]

## 14. 风险与假设

| 项 | 类型 |
|---|---|
| 「怕买错课」为真实主导动机 | HYPOTHESIS |
| 青绿干净可作视觉方向输入 | FACT（偏好）+ 完整规范 TODO |
| 学员图可商用 | 高风险；授权不全 |
| 定价未定导致价格页延期或改为「咨询了解」 | FACT |

## 15. 待确认事项

1. 主转化是「试听」还是「咨询」优先？两者表单是否合并？  
2. 首期是否出现具体价格？若否，价格入口如何文案化？  
3. 已购学员入口是否进官网导航？  
4. 竞品 URL 清单。  
5. 法务文案提供时间。  
6. 学员素材授权范围。

## 16. 设计范围

**In scope**

- 营销官网信息架构与（后续）页面视觉系统  
- 首页、产品线、课程摘要、团队、FAQ、咨询/试听、法务壳页  

**Out of scope**

- LMS、App、社区论坛、多语言、完整支付结账流  
- 伪造用户研究报告或竞品数据  

**渠道边界**：官网营销层；学习发生在第三方平台。[FACT]

## 17. 后续设计建议

1. 执行 `web-information-architecture` 锁定 Sitemap 与主路径。

3. 方向批准后执行 `web-design-system`。  
4. 价格与素材授权确认前，页面设计避免锁定不可逆商业承诺文案。

# web-information-architecture · 方法论

## 核心原则

1. **任务 > 部门**：导航标签应对用户目标说话。  
2. **内容盘点先于命名**：先有对象，再有菜单文案。  
3. **浅而清**：营销站关键转化通常应在 2–3 次有效点击内可达。  
4. **一种主分类轴**：避免同一 L1 混用「产品类型」与「用户角色」导致交叉重复。

## 选用方法

| 方法 | 何时用 | 无工具时 |
|---|---|---|
| 内容盘点表 | 始终 | 表格列出对象/来源/缺口 |
| 任务-内容矩阵 | 多任务站点 | 矩阵打勾，找孤儿内容 |
| 开放/封闭式分类思考 | 分类争议 | 写 2 套方案对比利弊 |
| 路径走查 | 有转化目标 | 逐步角色扮演，记摩擦 |
| Card Sorting / Tree Testing | 有真实用户可测时 | 标 TODO，不伪造成功率 |

## 反模式

- 为「看起来大」而增加空一级栏目。  
- 首页承担所有深层内容入口却无二级结构。  
- 博客/新闻默认 L1 而无内容策略。  
- 移动端把 P0 藏进「更多」。

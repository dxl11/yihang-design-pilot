# 示例指引

仓库案例：`examples/web/online-education-site/design-output/05-responsive-design/`

| page-id | 响应式重点 |
|---|---|
| `home` | Hero 分栏叠放；双产品线两列→一列；移动汉堡 + 粘性申请 |
| `course-detail` | 8+4 主侧栏→单列；侧栏 CTA 变底部/顶粘性；大纲手风琴 |

输入来自同案例 `04-page-design` 与 `design-tokens.json`。

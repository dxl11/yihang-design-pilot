## 必需大节（编号可与下表一致）

1. **Overview** — 页面任务、响应式目标、继承关系  
2. **Viewport Strategy** — 视口带与测试宽度  
3. **Breakpoint Rationale** — 每个采用断点的冲突→变化  
4. **Layout Transformation** — 栏数、侧栏、首屏、原因与 UX  
5. **Content Priority** — 顺序/折叠/条件模块理由  
6. **Navigation Adaptation** — 桌面/平板/移动导航行为  
7. **Component Behavior** — 本页组件跨屏规则  
8. **Interaction Adaptation** — hover/touch/focus/sticky 等  
9. **Typography & Spacing** — 引用 token 的字号/间距阶梯  
10. **Responsive Media** — 图比例、裁切、焦点  
11. **Accessibility** — 目标与待测（不宣称已认证）  
12. **Edge Cases** — 320、长标题、表溢出、放大等  
13. **Validation Checklist** — 设计检查 + NOT TESTED 标记  
14. **FACT / HYPOTHESIS / TODO** — 汇总  

多页批次用 `05-responsive-design/_index.md`。

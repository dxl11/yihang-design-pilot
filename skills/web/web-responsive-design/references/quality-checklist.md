# web-responsive-design · 质量检查

## 红线

- [ ] 有 page-design（或显式假设）与 tokens 继承声明  
- [ ] 断点理由基于冲突，非仅「手机要好看」  
- [ ] 布局转换含原因；非只写「变单栏」  
- [ ] 决策信息在窄屏仍可达（折叠可，静默删除不可）  
- [ ] 移动导航与主 CTA 方案完整  
- [ ] 关键信息不依赖 hover  
- [ ] 验证清单含 NOT TESTED（若未跑浏览器）  
- [ ] 未伪造 WCAG 认证 / 真机通过  
- [ ] 未编造价格、评价、研究结论  
- [ ] 未新增冲突的全局色板  

## 常见错误

- 所有页面复制同一套「768 变单栏」而无页面差异。  
- 定价比较在手机隐藏权益列。  
- 课程详情侧栏 CTA 消失且无粘性替代。  
- 把测试宽度写成「已在 iPhone 14 验证通过」却无证据。

# Design Fidelity Review

对照原始设计规格检查实现。可基于源码与已有证据；**不是** P2.5 浏览器视觉验证。无截图不得声称像素级一致。

## 对照项

1. 页面模块完整性  
2. 模块顺序  
3. 布局符合设计意图  
4. Token 映射正确  
5. 字体层级  
6. 组件符合设计系统  
7. 图片比例/裁切（有资源时）  
8. 交互状态  
9. 响应式规则  
10. 已确认 Review Issue 处理情况  

## 偏差分类

| 码 | 含义 |
|---|---|
| `MATCHED` | 与规格一致（基于所用证据） |
| `DEVIATED` | 有意或无意偏离，已说明 |
| `NOT_IMPLEMENTED` | 规格要求未做 |
| `NOT_VERIFIED` | 代码可能有，但缺运行/视觉证据 |
| `NOT_APPLICABLE` | 本页/本栈不适用 |

## 偏差记录字段

- 偏差 ID  
- 对应设计输入  
- 实现位置（文件/组件）  
- 描述、影响、原因  
- 建议处理  

`NOT_VERIFIED` **不得**写成 PASS。

# Web Design Workflow · 阶段交接契约

## brief → IA

IA 开始前 `design-brief.md` 至少含：目标、受众、主转化、不做列表。

## IA → visual direction

`ia.md` 至少含：页面列表、首页首屏信息优先级。

## visual direction → page design

必须存在：

- `direction-approved.md`（用户原话或明示跳过理由）  
- `visual-direction.md`（色、字、骨架、图像语言、禁止项）

## page design → review

- 入口 HTML 可打开  
- 控制台无故意忽略的 JS 错误（若可检测）  
- 文案非 Lorem  

## Review 清单（P1 人工/Agent）

### Red

- 裂图 / 假 logo  
- 正文过小或对比不足（明显不可读）  
- 未遵守已批准方向的主色/字体配对（无明显继承）  
- 无用户确认却宣称方向已定  

### Yellow

- 模板装饰（全大写小标签、无意义 01/02/03、按钮尾箭头滥用）  
- 首屏堆满统计条而无题材锚点

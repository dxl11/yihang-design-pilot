# 示例：本地咖啡订阅落地页

## 输入

```text
目标：让城市白领完成首周订阅。
受众：25–40 岁，在意品质与时间。
约束：已有深绿 logo；不要娱乐风；需要三个方向。
```

## 合格输出（摘要）

### D1 — 器物特写

- 骨架：首屏单张杯壁凝露特写 + 一句承诺，纵向慢节奏  
- 色：logo 深绿作主色，纸感米白底，一点焦糖强调；论证来自包装摄影  
- 字：衬线 display + 无衬线 body  
- 图像：真实器物摄影，禁止插画吉祥物  
- 禁止：三列均质特性卡开场  

### D2 — 编辑栅格

- 骨架：模块网格 + 细规则线，价格与产地成「条目」  
- 色：近黑 / 白 / 单一强调绿  
- 字：紧字距无衬线巨标题压 14px 说明  
- 图像：小图嵌入栏内，非全屏 Hero  

### D3 — 订阅仪表

- 骨架：首屏即「下周菜单」界面舞台，周围留白  
- 色：中性灰阶 + logo 绿仅用于主 CTA  
- 字：UI 无衬线层级  
- 图像：产品 UI 截图（诚实占位须标明）  
- 风险：易做成 Dashboard；须控制信息密度  

## 不合格反例

三方向均为「浅底 + 中部大标题 + 下方三卡」，仅强调色分别为绿/棕/黑——判定为换皮，须重做。

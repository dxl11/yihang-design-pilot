# 视觉方向方法论

## 1. 方向必须「骨架不同」

验收提问：把三方向都改成灰度，是否仍能分辨？  
若不能，则只是换皮，必须重做布局策略（对齐、比例、首屏主角、信息密度）。

## 2. 色彩三步（采样 → 收敛 → 论证）

1. **采样**：品牌 logo / 产品真图 / 题材文化色，禁止无来源的网红默认蓝紫。  
2. **收敛**：有彩色 2–3 个；中性色写成明度阶（如 5 级）。有彩色色相角尽量拉开或明度差拉开。  
3. **论证**：每个主色一句话「为什么是这个」。

大面积底色建议控制 chroma（屏幕「印刷感」），高饱和留给小面积强调。

## 3. 字体

- 必须成对：Display + Body（可加 Mono 仅用于代码/数据）。  
- 写清字重与大致字号角色（H1 / 正文 / 元信息），网页正文规划 ≥14px。  
- 中文：说明是系统栈还是指定开源字体；不要点名未授权商业字体当交付依赖。

## 4. 布局骨架词汇（选用并写具体）

示例骨架（须改写成该项目语言）：

- 巨字压图：标题占视口主导，图作纹理  
- 分栏编辑：严格栅格 + 规则线  
- 画廊：大图叙事，文字边缘注释  
- 产品舞台：产品/UI 居中，周围极简  
- 文档营销：左导航气质 + 右内容，但首屏仍要有「世界入口」

禁止三方向都落入「大 Hero + 三列特性卡 + 评价墙」而未说明差异。

## 5. 图像语言

先定主角素材类型：真实摄影 / UI 截图 / 程序化几何 / 数据图形 / 字体即图像。  
无图时写清诚实占位策略，禁止用假 logo 墙与假评价。

## 6. 与品牌的关系

| 情况 | 做法 |
|---|---|
| 有 BrandProfile | 色/字/logo 用法服从品牌；方向差异放在布局与材质 |
| 无品牌 | 从题材采样建立临时 tokens，并标记为 provisional |

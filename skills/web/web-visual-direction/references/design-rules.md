# 设计红线与默认禁止（Web 视觉方向）

下列条款用于方向提案阶段的自检。页面实现阶段仍应再次执行。

## 必须

1. 方向说明里包含：**骨架、色、字、图像语言、禁止项**。  
2. 正文可读性预算：规划对比度 ≥4.5:1；正文 ≥14px。  
3. 有具名品牌/产品时，方向不得用几何剪影冒充官方 logo。

## 禁止（默认）

1. 无题材依据的紫粉渐变装饰作主视觉。  
2. 三方向共用同一卡片栅格，仅改强调色。  
3. 用「高级 / 大气 / 国际」替代参数。  
4. 编造用户评价、客户 logo 墙、下载量。  
5. 把整页做成与信息无关的万能隐喻（地铁图、终端、报纸头版）——三方向中最多一个，且须论证「去掉后信息是否更差」。

## 外观家族提醒

暖纸衬线、深底单点缀、细线报刊、圆角卡片套件等**可以**使用，但：

- 三方向不应挤在同一家族。  
- 若用户近期项目刚用过同一家族，应主动换骨架（若可知）。

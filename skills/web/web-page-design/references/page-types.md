# 页面类型与差异化策略

设计前必须判定类型。禁止用同一模板硬套。下表为默认策略，可按 Brief 覆盖。

| 类型 | 主任务 | 首屏重点 | 中段重点 | 主 CTA 逻辑 |
|---|---|---|---|---|
| Home / Landing | 识别是否相关 + 导向深页或转化 | 品牌主张、为谁、教/卖什么 | 产品线入口、信任摘要 | 主：申请/试用；次：看课程/产品 |
| Product Page | 理解单产品价值与差异 | 产品名+一句话价值 | 能力、场景、对比入口 | 试用 / 了解方案 |
| Service Page | 理解服务方式与边界 | 服务结果承诺（可验证措辞） | 流程、范围、交付物 | 咨询 |
| Course Detail | 判断「适不适合我」与报名 | 课程定位、适合人群 | 大纲、收益、教研、顾虑 | 试听/报名；忌空喊促销 |
| Pricing | 比较套餐并降低购买焦虑 | 套餐框架或「如何选择」 | 权益对比、解释、风险消除 | 购买或「咨询定价」（价格未定时） |
| Feature Page | 理解某一能力 | 能力名称+用户收益 | 细节、集成、限制 | 看方案 / 试用 |
| Solution Page | 对号入座行业/场景 | 场景痛点共鸣 | 方案步骤、证明 | 获取方案 |
| Case Study | 建立「别人做成了」的信任 | 客户语境与结果（须真实） | 过程、指标、引用 | 类似咨询 |
| Article / Content | 阅读与理解 | 标题与摘要 | 正文层级、相关阅读 | 软 CTA |
| Conversion Page | 完成单一转化 | 表单或关键步骤极简 | 仅必要信任与顾虑 | 提交；减少分心链接 |
| Contact Page | 建立联系 | 联系方式/表单目的 | FAQ、响应时效（若已知） | 发送 |

## 选型检查

- 类型是否与 IA 路径一致？若为验证页超出 Sitemap，须在 Overview 声明。  
- 是否误把 Pricing 做成第二个 Home？  
- Course Detail 是否缺少「适合人群 / 不适合谁」？

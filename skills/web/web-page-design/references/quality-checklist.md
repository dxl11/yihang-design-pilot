# web-page-design · 质量检查清单

## 红线（任一项失败不得宣称页面设计完成）

- [ ] 未在缺少方向批准时假装视觉已定稿  
- [ ] 布局与颜色引用现有 Design System / tokens，无平行全局色名（如另造 `blue-1` 体系）  
- [ ] 未伪造用户研究「已验证」、客户评价原文、未确认价格/人数/成功率  
- [ ] 主转化 CTA 写明点击后行为与成功/失败态  
- [ ] 页面类型策略与模块选择匹配（非万能三列模板）  
- [ ] 信息层级含顺序理由  

## 强烈建议

- [ ] 首屏可在 5–10 秒内说出「这是谁的站、为我吗、下一步」  
- [ ] 信任模块有来源策略；无素材则条件隐藏或 TODO  
- [ ] 表单有标签、错误文案、加载防重复  
- [ ] 标题层级语义清楚（H1 唯一）  
- [ ] 对比度/焦点列为待测，未宣称 WCAG 认证通过  
- [ ] 与 IA 路径一致或已声明验证性偏离  
- [ ] 可交接给 `web-responsive-design` / `web-design-review` / 实现  

## 常见错误

- 首页首屏堆满无来源统计条。  
- 价格页在定价未定时写死套餐价并标 FACT。  
- 课程详情只有大纲没有「适合/不适合」。  
- 全页白卡片圆角重复，无视已选视觉方向。  
- 交互只有「hover 变色」无业务响应。

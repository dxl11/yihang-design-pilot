# 示例指引

## 仓库贯穿案例

路径：`examples/web/online-education-site/design-output/04-page-design/`

| page-id | 类型 | 路径 | 设计要点 |
|---|---|---|---|
| `home` | Home | `/` | 主张 + 双产品线入口 + 申请；继承 Direction B 首屏骨架 |
| `course-detail` | Course Detail | `/courses/product-design-foundation`（示例课） | 适合人群、大纲、信任、试听；IA 曾标单课为 P2，案例中声明验证页 |
| `pricing` | Pricing | `/pricing` | **不写死未确认价格**；套餐框架 + 咨询定价；IA 曾未纳入首期 Sitemap |

输入一律来自同目录上级的 `01`–`03`、视觉方向与 tokens。

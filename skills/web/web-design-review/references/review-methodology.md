# web-design-review · 九维方法论

## 维度与对照物

| 维度 | 主要对照 | 无截图/无运行时 |
|---|---|---|
| Visual Quality | Direction、System、截图 | 仅审规格意图；呈现态 NOT TESTED |
| Design System Consistency | System、Tokens、Page/Responsive | 可审「规格是否引用 tokens」；像素一致需截图 |
| Information Architecture | Brief、IA、Page Structure | 可审任务对齐与模块顺序逻辑 |
| Interaction | Page Interaction、浏览器 | 规格可审完整性；行为 NOT TESTED（无浏览器） |
| Responsive | Responsive 规格、多视口截图/浏览器 | 策略逻辑可审；溢出/触达实测 NOT TESTED |
| Accessibility | System a11y、专用测试 | 目标与缺口可审；对比度/读屏实测 NOT TESTED |
| Business Goals | Brief、Page Overview | 逻辑对齐可审；转化率不可编造 |
| Content Quality | Page Content、Brief | PLACEHOLDER/假数据可抓；真实性需来源 |
| Overall Experience | 以上综合 | CRITICAL 否决高分假象 |

## 评分（可选 0–100）

- 仅对**有足够证据**的维度评分。  
- `NOT TESTED` **不得**记 100 或按 PASS 计入均值。  
- 存在任一 **CRITICAL** Issue → 整体不得 APPROVED；Overall 分上限建议 ≤40 或直接不汇总、改结论驱动。  
- 证据大面积缺失 → 输出 `INSUFFICIENT_EVIDENCE`，不强行总分。

## 普通 AI vs 专业

| 普通 | 专业 |
|---|---|
| 「看起来挺好」 | 维度状态 + 证据类型 |
| 「优化一下」 | 改什么、验什么、对哪条规范 |
| 无图写视觉通过 | Visual = NOT TESTED |
| 用均分掩盖主 CTA 失效 | CRITICAL 否决 |

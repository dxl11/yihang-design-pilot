# web-design-review · Quality Gate

## 红线（审查报告自身）

- [ ] 有 Evidence Coverage  
- [ ] 无截图却 Visual 呈现 PASS → 失败  
- [ ] 无浏览器却 Interaction/Responsive 运行 PASS → 失败  
- [ ] 无测量却宣称对比度达标 / WCAG 认证 → 失败  
- [ ] FAIL 项有证据或明确 CASE_DEMO  
- [ ] 整改建议含验收标准  
- [ ] CRITICAL（确证）时结论非 APPROVED  
- [ ] 大量 NOT TESTED 时未强行 APPROVED  
- [ ] 验证页 IA 状态已披露  

## 无效整改用语（禁止单独出现）

「优化页面」「提升视觉」「改善体验」「增强一致性」——必须落到具体改动与验收。

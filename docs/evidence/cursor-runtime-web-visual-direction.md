## 产出摘要（按 Skill 字段）

### D1 — 深夜自习室（克制编辑）

- **策略**：把学习场景做成安静的夜读空间，强调专注而非促销。  
- **色彩**：近黑底 `#0E1116`；暖纸正文区 `#F4F0E6`；强调仅用品牌可替换的琥珀 `#D97706`（provisional，来自「台灯色」题材采样）。  
- **字体**：衬线 Display（章节名）+ 无衬线 Body（课程说明）；中文用系统宋/黑体栈并标注 provisional。  
- **布局骨架**：首屏左 40% 巨字课程承诺，右 60% 单张真实书桌摄影；下方两栏「路径 / 今晚任务」，无三列均质卡片开场。  
- **图像语言**：真实桌面/笔记摄影；禁止假证书墙。  
- **禁止**：紫粉渐变、吉祥物堆叠。  

### D2 — 模块课表栅格（中性信息）

- **策略**：教育产品的「课表」本身做主角，信息密度服务扫读。  
- **色彩**：白底 `#FFFFFF`；墨色 `#111`；单一强调蓝绿 `#0F766E`（来自「进度完成」语义，非默认科技蓝紫）。  
- **字体**：紧字距无衬线巨标题 + 小号等宽仅用于课时编号。  
- **布局骨架**：严格 12 栏栅格 + 1px 规则线；首屏即「本周模块」表格式区块，而非大 Hero 图。  
- **图像语言**：小尺寸讲师/教室图嵌入格内；数据（完成率）用条带而非装饰插画。  
- **禁止**：与 D1 相同的左右分屏巨字结构。  

### D3 — 作品舞台（大胆作品集）

- **策略**：年轻专业人士在意作品集展示；首屏用学员产出作为信任锚。  
- **色彩**：中性灰阶舞台 `#F3F4F6`/`#1F2937`；强调仅 CTA 使用高饱和品牌位（占位 `#E11D48`，须替换为真实品牌色）。  
- **字体**：几何无衬线全站；标题更大、正文更短。  
- **布局骨架**：首屏中央「作品画框」舞台（UI/作业截图），上下极简导航与一句主张；滚动后才出现课程信息。  
- **图像语言**：真实作业/UI 截图；无截图则诚实灰框标注「待替换」。  
- **风险**：易滑向 Dashboard；须控制首屏控件数量 ≤3。
